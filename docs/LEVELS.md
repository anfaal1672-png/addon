# レベル設計の詳細

すべての数値は `packs/PvPPracticeBP/scripts/config.js` の `LEVELS` にあります。
ここでは各パラメータが**実際にどう挙動へ効くのか**を説明します。

チューニングしたいときは `config.js` を編集して `npm run check` を走らせてください。
チェッカーが「レベルが上がるほど強くなっているか」の単調性を検証します。

---

## パラメータ一覧

| キー | 単位 | 効き方 | Lv1 → Lv5 |
|---|---|---|---|
| `reactionTicks` | ティック | ボットが相手の位置・速度を更新する間隔。この値が大きいほど「過去の位置」に向かって殴る | 12 → 1 |
| `aimError` | 度 | 視線に乗る誤差。4〜12ティックごとに再抽選されるので、細かい震えではなく「ズレたまま殴る」挙動になる | 22 → 1.0 |
| `turnSpeed` | 度/ティック | 首の追従速度。低いと急な回り込みに置いていかれる | 7 → 55 |
| `cps` | 回/秒 | 攻撃の試行間隔（`20 / cps` ティック） | 2.2 → 14 |
| `iframeAwareness` | 0–1 | 相手が無敵時間中のとき、この確率で攻撃を**見送る**。1.0なら無敵切れの瞬間だけ殴る | 0 → 1.0 |
| `reach` | ブロック | 攻撃が届く距離。上限は統合版の3.0 | 2.5 → 3.05 |
| `hitChance` | 0–1 | 射程内スイングの基礎命中率。実際にはエイム誤差でさらに減衰する | 0.55 → 0.99 |
| `critSkill` | 0–1 | 射程内かつ接地時に、ジャンプしてから落下中に殴る（1.5倍）確率 | 0 → 0.96 |
| `strafe` | 0–1 | 円運動の強さ。0だと正面から突っ込むだけ | 0 → 1.0 |
| `sprintSkill` | 0–1 | ダッシュを維持する割合 | 0.15 → 1.0 |
| `wtapSkill` | 0–1 | 命中直後にダッシュを切る長さと、与えるノックバックの増加量 | 0 → 1.0 |
| `comboSkill` | 0–1 | 命中後に追撃モードへ入る長さ、偏差エイムの強さ、体力の低い相手を狙う判断 | 0 → 1.0 |
| `kbControl` | 0–1 | 被弾直後の移動速度補正。高いほど吹き飛びを押し返す | 0 → 0.92 |
| `dodgeSkill` | 0–1 | 飛来する矢を検知して横に跳ぶ確率 | 0 → 0.95 |
| `bowSkill` | 0–1 | 弓の引き時間、偏差量、重力補正量、拡散の狭さをまとめて制御 | 0.15 → 0.98 |
| `buildSkill` | 0–1 | 置きブロック・タワー・橋・MLG水を使う判断力 | 0 → 0.95 |
| `healThreshold` | 0–1 | この体力割合を下回ると金リンゴを食べる（0なら食べない） | 0 → 0.6 |
| `retreatSkill` | 0–1 | コンボを食らったときに離脱を選ぶ度合い | 0.1 → 0.95 |
| `jitter` | 0–1 | ランダムな判断ミス。ターゲット固執や無謀な落下に効く | 0.55 → 0 |

## なぜ CPS を上げるだけでは強くならないのか

統合版では被弾したエンティティに**10ティック（0.5秒）の無敵時間**が入ります。
つまり理論上の最大DPSは「毎秒2発」で頭打ちです。

CPSが14あっても、無敵時間中に振った12発は完全な無駄になります。
本当に差がつくのは `iframeAwareness` のほうで、

- **Lv1**（awareness 0）: 無敵中でも構わず振る。実質DPSは2発/秒より落ちる（狙いも甘いので）
- **Lv5**（awareness 1.0）: 無敵が切れる瞬間にだけ振る。毎回クリティカルを乗せるので理論値ちょうど

高CPSは「無敵切れの瞬間を取りこぼさない解像度」として効いてきます。
これは実際の統合版PvPの上手さの構造そのものです。

## 独自の強さを作る

例えば「弓だけ世界最高峰、近接は初心者」というボットを作りたい場合、
`LEVELS` に6つ目のプロファイルを足すのではなく、既存レベルの値を書き換えるのが簡単です。

```js
// config.js の LEVELS[0]（Lv1）を弓特化にする
{
  level: 1,
  id: 'sniper',
  reactionTicks: 12,
  aimError: 22,
  cps: 2.2,
  hitChance: 0.55,
  bowSkill: 0.98,   // ← 弓だけ最高
  dodgeSkill: 0.95, // ← 矢も避ける
  // ...残りはそのまま
}
```

`npm run check` の単調性チェックはレベル間の一貫性を見るためのものなので、
意図的に崩す場合は `tools/check.mjs` の `monotonic` リストから該当キーを外してください。
